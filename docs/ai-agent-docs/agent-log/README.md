# Archived Agent Log Mirror

This directory is an archived mirror from older AI-agent documentation imports.
It is **not** the active SOP-NLT-001 agent-log location.

Use these current paths instead:

- Session-start registrations: `docs/agent-log/registrations/`
- Session-end handoffs: `docs/agent-log/handoffs/`
- Thread ownership/status: `docs/active-threads.md`

## How to use files in this archive

- Treat records here as historical context.
- Verify branch names, PR URLs, and workflow status against current source files
  and `docs/agent-log/` before relying on them.
- Do not add new records here unless you are intentionally preserving a legacy
  artifact.
